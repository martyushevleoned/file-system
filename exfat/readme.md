# exFAT

## Пункт 1
Создать виртуальный диск и отформатировать его в файловой системе exFAT. 

```shell
dd if=/dev/zero of=exfat.img bs=1M count=50  # Создать образ диска размером 50 МБ, заполненный нулями
mkfs.exfat exfat.img                         # Создать файловую систему exFAT
```

```shell
file exfat.img
fsck.exfat -v exfat.img
```

```dump
exfatprogs version : 1.2.9
sector size:  512.00 B
cluster size: 4.00 KB
volume size:  50.00 MB
exfat.img: clean. directories 1, files 0
```

## Пункт 3
| Смещение | Длина, байт | Параметр                                             | raw hex                   | dec    |
| -------- | ----------- | ---------------------------------------------------- | ------------------------- | ------ |
| 0x48     | 8           | Количество секторов в файловой системе               | `00 90 01 00 00 00 00 00` | 102400 |
| 0x50     | 4           | Сектор, в котором начинается FAT                     | `00 08 00 00`             | 2048   |
| 0x54     | 4           | Размер FAT в секторах                                | `62 00 00 00`             | 98     |
| 0x58     | 4           | Сектор, в котором начинается битовая карта кластеров | `00 10 00 00`             | 4096   |
| 0x5C     | 4           | Количество кластеров                                 | `00 30 00 00`             | 768    |
| 0x60     | 4           | Кластер корневого каталога                           | `05 00 00 00`             | 5      |
| 0x6C     | 1           | Размер сектора (степень 2)                           | `09`                      | 9      |
| 0x6D     | 1           | Кластерный множитель (степень 2)                     | `03`                      | 3      |

Проанализировать содержимое загрузочной записи и определить следующие параметры: 
1) размер сектора = 512 байт = 200h
2) размер кластера = 8 секторов = 4096 = 1000h
3) количество кластеров в файловой системе = 768
4) начальный сектор FAT = 2048 сектор = 100000h
5) смещение битовой карты = 4096 секторов = 200000h
6) смещение первого кластера = битовая карта - 2 кластера = 200000h - 2 × 1000h = 1FE000h
7) начальный сектор корневого каталога = 5-й кластер = 1FE000h + 5 × 1000h = 203000h

## Пункт 4
При помощи «Проводника» создать на диске не менее одного каталога и двух файлов:
1) директория
2) текстовый документ с коротким именем (не более 8 латинских символов)
3) изображение формата BMP с длинным именем (более 8 произвольных символов).

```shell
# Монтирование образа
mkdir -p /mnt/exfat
mount -o loop exfat.img /mnt/exfat
mount | grep /mnt/exfat

# Создать файлы
mkdir /mnt/exfat/folder
echo 'text' > /mnt/exfat/file.txt
cp ../image.bmp /mnt/exfat/image-name.bmp
ls /mnt/exfat

# Отмонтировать образ
umount /mnt/exfat
mount | grep /mnt/exfat
```

## Пункт 7
Удалить один из файлов без помещения в корзину. 
Обновить содержимое диска.
Какие изменения произошли в корневом каталоге?
