# FAT 16
## Пункт 1
Создать виртуальный диск и отформатировать его в файловой системе FAT16
```shell
dd if=/dev/zero of=fat16.img bs=1M count=10 # Создать образ диска размером 10 мб заполненный нулями
mkfs.vfat -F 16 fat16.img  # Создать файловую систему FAT16
```

## Пункт 3

| Смещение  | количество байт | параметр | raw hex | hex | dec |
| --------- | --------------- | -------- | ------- | --- | --- |
| 0x0B | 2 | Количество байт в секторе |00 02 | 200 | 512 |
| 0x0D | 1 | Количество секторов в кластере | 04 | 4 | 4 |
| 0x11 | 2 | Максимальное количество 32-байтовых записей в корневом каталоге |00 02 | 200 | 512 |
| 0x13 | 2 | Количество секторов в файловой системe | 00 50 | 5000 | 20480 |
| 0x20 | 4 | Количество секторов в файловой системe | 00 00 00 00 | 0 | 0 |
| 0x0E | 2 | Размер зарезервированной области (в секторах) | 04 00 | 4 | 4 |
| 0x10 | 1 | Количество копий FAT | 02 | 2 | 2 |
| 0x16 | 2 | Размер FAT (в секторах)  | 14 00 | 14 | 20 |

Проанализировать содержимое загрузочной записи и определить следующие параметры:
1) размер сектора = 200h байт = 512 байт
2) размер кластера = 4 сектора = 2048 байт
3) размер корневой директории = количество 32-байтовых записей * 32 / размер сектора = 32 сектора
4) количество кластеров в файловой системе = 20480 секторов - 4 зарезервировано - 2 * 20 FAT - 32 корневой директории = 20404 секторов = 5101 кластер
5) размер зарезервированной области = 4 сектора = 800h байт
6) количество копий FAT = 2
7) размер FAT = 20 секторов

## Пункт 4

Определить смещения:
1) область FAT = 4 сектора зарезервировано * размер сектора = 800h
2) корневого каталога = смещение области FAT + (2 таблицы FAT по 20 секторов * размер сектора) = 5800h
3) область данных = смещение корневого каталога + размер корневого каталога = 9800h
3) 2-го кластера = начало области данных + 2 кластера = a800h

## Пункт 5
При помощи «Проводника» создать на диске:
* каталог
* текстовый документ с коротким именем (не более 8 латинских символов)
* изображение формата BMP с длинным именем (более 8 произвольных символов).

Примонтировать образ
```shell
mount -o loop fat16.img /mnt/fat16
mount | grep /mnt/fat16
```

Создать файлы
```shell
cp image.bmp /mnt/fat16/image-name.bmp
cd /mnt/fat16
echo 'text' > /mnt/fat16/file.txt
mkdir /mnt/fat16/folder
```

Отмонтировать образ
```shell
umount /mnt/fat16
```

## Пункт 7

Информация из файловой записи:
| Смещение  | количество байт | параметр |
| --------- | --------------- | -------- |
| 0x14 | 2 | Старшие 2 байта номера первого кластера |
| 0x1A | 2 | Младшие 2 байта номера первого кластера |
| 0x1C | 4 | Размер файла |

Содержимое таблицы FAT:
* Цепочка кластеров состоит из 2х байтовых записей
* Первые 2 2х байторые записи зарезервированы
* [3, 514] записи файла `image-name.bmp` ссылкаются на последующую запись и заканчиваются `ff ff`
* Последующие 2 записи `ff ff` т.к. содержимое `file.txt` и `folder` занимают по одному кластеру

## Пункт 9

Восстановить данные удаленного файла в новый файл на другом логическом диске, скопировав требуемое количество байт в новый файл.

```shell
dd if=fat16.img of=recovered.txt bs=1 skip=$((0x10b000)) count=5
```
Зная размер файла и цепочку кластеров можно восставновить файл при условии, что данные не были перезаписаны.
* Смещение = 0x10b000
* Размер = 5
