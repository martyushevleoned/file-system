# FAT32
# Пункт 1
Создать виртуальный диск и отформатировать его в файловой системе FAT3.

```shell
dd if=/dev/zero of=fat32.img bs=1M count=50 # Создать образ диска размером 50 мб заполненный нулями
mkfs.vfat -F 32 fat32.img # Создать файловую систему FAT32
```

# Пункт 3

| Смещение | Размер | Параметр                  | raw hex       | dec    |
| -------- | ------ | ------------------------- | ------------- | ------ |
| 0x0B     | 2      | Размер сектора            | `00 02`       | 512    |
| 0x0D     | 1      | Секторов на кластер       | `01`          | 1      |
| 0x20     | 4      | Количество секторов в ФС  | `00 90 01 00` | 102400 |
| 0x0E     | 2      | Зарезервированные сектора | `20 00`       | 32     |
| 0x10     | 1      | Количество FAT            | `02`          | 2      |
| 0x24     | 4      | Размер FAT                | `14 03 00 00` | 788    |
| 0x2C     | 4      | Номер корневого кластера  | `02 00 00 00` | 2      |

Проанализировать содержимое загрузочной записи и определить следующие параметры:
1) размер сектора = 512 байт
2) размер кластера = 1 сектор = 512 байт
3) количество кластеров в файловой системе = (102400 всего - 32 зарезервировано - 2 FAT по 788) секторов / 1 сектор в кластере = 100792
4) размер зарезервированной области = 32 сектора
5) количество копий FAT = 2
6) размер FAT = 788 секторов

# Пункт 4
Определить смещения:
1) FAT = 32 сектора * 200h = 4000h
2) область данных = FAT + размер FAT = 4000h + (2 FAT по 788 секторов по 512 байт) = с9000h
3) корневой каталог = 2й кластер = область данных = с9000h

# Пункт 5
Cоздать на диске: 
1) каталог
2) текстовый документ с коротким именем (не более 8 латинских символов)
3) изображение формата BMP с длинным именем (более 8 произвольных символов).

```shell
# Монтирование образа
mkdir -p /mnt/fat32
mount -o loop fat32.img /mnt/fat32
mount | grep /mnt/fat32

# Создать файлы
mkdir /mnt/fat32/folder
echo 'text' > /mnt/fat32/file.txt
cp ../image.bmp /mnt/fat32/image-name.bmp
ls /mnt/fat32

# Отмонтировать образ
umount /mnt/fat32
mount | grep /mnt/fat32
```
