## Пункт 1

(имя файла должно состоять из вашей фамилии и имени) и текстом, набранными латинскими символами.

mount -o loop ntfs.img /mnt/ntfs
echo "Martyushev Leoned RI-511050" > /mnt/ntfs/name.txt
umount /mnt/ntfs

## Пункт 4
1) Найти массив корректировки секторов файловой записи.
2) Найти шаблон корректировки и байты, которые должны находиться в конце каждого сектора файловой записи.

| Поле | Смещение (от начала записи) | Размер (байт) | Значение |
| ---- | --------------------------- | ------------- | -------- |
| Смещение N массива корректировки файловой записи | 0x04 | 2 | `30 00` |
| Размер массива корректировки файловой записи (L — в словах) | 0x06 | 2 | `03 00` |

1) Массив корректировки = 3 слова (6 байт) начиная со смещения 14030h = `06 00 00 00 00 00`
2) Шаблон корректировки = `06 00`

## Пункт 5
1) Найти флаги использования и каталога файловой записи.
2) Убедиться, что файл используется.

| Поле | Смещение (от начала записи) | Размер (байт) | Значение |
| ---- | --------------------------- | ------------- | -------- |
| Флаги использования и каталога (0x01 — запись используется, 0x02 — каталог) | 0x16 | 2 | `01 00` = `IN USE` |
| Реальный размер файловой записи | 0x18 | 4 | `98 01 00 00` |
| Выделенный размер файловой записи | 0x1C | 4 | `00 04 00 00` |
| Файловая ссылка на базовую файловую запись | 0x20 | 8 | `00 00 00 00 00 00 00 00` |
| Идентификатор, который необходимо присвоить следующему создаваемому атрибуту | 0x28 | 2 | `04 00` |
