# NTFS

Создание образа
```shell
dd if=/dev/zero of=ntfs.img bs=1M count=50
mkfs.ntfs -F ntfs.img
ntfsinfo -m ntfs.img
```

Работа с образом
```shell
mount ntfs.img /mnt/ntfs
umount /mnt/ntfs
hexdump -C ntfs.img > dump.log
```

### Пункт 2.
* Найти атрибут $INDEX_ROOT, разобрать его содержимое.
* У атрибута присутствует имя?

Атрибут:
* флаг -> `90 00 00 00`
* смещение -> 0x00014158
* размер -> `50 00 00 00`

Формат области данных атрибута $INDEX_ROOT
| Смещение  | Длина, байт 	| значение  | Описание |
|-----------|---------------|---------- |----------|
| 0х20	    | 4	            | `30 00 00 00` | Тип атрибута в индексе |
| 0х24	    | 4	            | `01 00 00 00` | Правило сортировки |
| 0х28	    | 4	            | `00 10 00 00` | Размер каждой индексной записи в байтах |
| 0х2С	    | 1	            | `01` | Размер каждой индексной записи в кластерах |
| 0х2D	    | 3	            | `00 00 00` | Не используется |
| 0х30	    |               | | Заголовок узла |

Формат заголовка индексного узла (0x00014188)
| Смещение | Длина, байт 	| значение | Описание |
| -------- | -------------- | -------- | -------- |
| 0х30	   | 4	            | `10 00 00 00` | Смещение начала списка индексных элементов (относительно начала заголовка узла) |
| 0х34	   | 4	            | `20 00 00 00` | Смещение конца используемой части списка индексных элементов (относительно начала заголовка узла) |
| 0х38	   | 4	            | `20 00 00 00` | Смещение конца выделенного буфера списка индексных элементов (относительно начала заголовка узла) |
| 0х3С	   | 4	            | `00 00 00 00` | Флаги |
